# ACME Salary Management System

A web-based employee salary management platform
for organizations operating across multiple countries.

## Technology Stack

### Backend
- Ruby on Rails 8
- MySQL
- Redis
- Sidekiq

### Frontend
- React
- Vite
- Tailwind CSS
- shadcn/ui

## Features

- Employee Management
- Salary Management
- Salary History
- Dashboard & Analytics
- CSV Import/Export
- Salary Reports

## Project Structure

- backend: Rails API
- frontend: React application
- docs: Requirements and technical documentation
